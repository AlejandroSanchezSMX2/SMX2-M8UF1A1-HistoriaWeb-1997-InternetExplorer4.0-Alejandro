# Internet Explorer 4.0

## Origen de Internet Explorer 4.0:

### ¿Com es va originar Internet Explorer?
-Abans d'anomenar-se Internet Explorer, s'anomenava "Microsoft Explorer" i després d'un temps es va acabar anomenant "Windows Internet Explorer" i finalment va acabar amb el nom de "Internet Explorer". Es va llençar per primera vegada com part d'un paquet complementari per a Windows 95.
